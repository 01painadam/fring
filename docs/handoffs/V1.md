## Goal and acceptance criteria
REBOUND reference run for single-particle precession (serves C2). *Done when* scripts produce reference files and comparison plots in `validation/reports/`. The Rust code measured ϖ̇ and Ω̇ at r = 100000, 140222.43 and 180000 km (e = i = 1e-3) against PLAN 7.2 with J2, J4, J6. A6 target: agreement with PLAN 7.2 to better than 0.01 %.

## Done
- `validation/` uv project (Python 3.12; rebound 5.2.2, reboundx 5.1.0, numpy 2.5.4, scipy 1.18.1, matplotlib 3.11.2, pytest).
- `fring_ref/force.py`: J2, J4, J6 acceleration written from PLAN 7.1; REBOUND `additional_forces` callback (acts on bodies 1.. relative to body 0, Saturn); PLAN 7.2 frequencies.
- Tests (`validation/tests/test_force.py`): gradient versus finite difference (< 1e-8); equatorial circular orbit versus PLAN 7.2; trajectory versus REBOUNDx `gravitational_harmonics` (J2 and J4 only).
- `scripts/v1_precession.py`: IAS15 (epsilon 1e-9), 200 orbits, three radii; two independent measurements (event timing of pericentre and node passages, and a least-squares frequency fit of n, kappa, nu); sensitivity checks.
- Outputs: `validation/reference/v1_precession.json`, `v1_series_r*.csv`, `validation/reports/v1_precession.png`, `validation/reports/v1.md`.

## Decisions made (link ADRs)
- The measured ϖ̇ and Ω̇ use event timing and a frequency fit, not osculating elements: the osculating eccentricity of a J2-perturbed circular orbit (about 4.5e-3 at the core) exceeds e = 1e-3, so osculating ϖ rotates at n and not at n - kappa.
- Saturn's reaction to the J force is neglected (relative order 3e-10 for the moons); it is irrelevant for V1, where the particle is massless.
