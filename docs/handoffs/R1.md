Role: A5  Branch: ws/a5-r1  Status: review

## Goal and acceptance criteria

From `docs/PLAN.md` section 9: `fring-run` CLI reads a config, runs a backend, writes snapshots and `meta.json`, shows progress. *Done when:* a CPU run of 10^4 particles for 1 year completes from one config file.

## Done

- `apps/fring-run`: `cli.rs` (hand-parsed flags), `lib.rs` (the run), `sysinfo.rs` (git hash, machine), thin `main.rs`. No new dependencies.
- Flow: config, refuse unbuilt features (gpu, arc, collisions other than none), params, ephemeris (1800 s interval, covers `n_steps * step_s`), initial particles, backend; only then the output directory is created. Then `config.toml`, `moons.bin`, frames and `stats.csv`, and `meta.json` last (present = finished).
- Frames are written at step 0, every `frame_every_steps`, and at the last step. Stats rows likewise. `moons.bin` has one record per frame time.
- Frame conversion: rotate in f64 (`inertial_to_rotating`), then round to f32. `t_ref = 0`.
- Output directory must not exist or must be empty; a run is never overwritten (no `--force`).
- Exit codes: 0 done, 1 failure during the run, 2 usage, config, params or not implemented.
- `stats.csv` crash rule: a last line without a newline is dropped (`read_stats_csv_report` says so). Specified in `docs/snapshot-format.md` section 8.
- Acceptance run (release, Apple M4, 10 threads): 14.2 s wall, 87,660 steps, 62 frames, 602 stats rows, 9.9 MB, about 64 M particle-steps/s while stepping.

## Open questions / blockers

- Ctrl-C is not handled (no signal crate): a stopped run leaves a directory without `meta.json`.
- `params_dir` is relative to the working directory (as the config documents), so run from the repository root.
- `git_hash` uses the working directory, not the binary's location.
