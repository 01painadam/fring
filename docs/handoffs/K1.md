## Decisions made (link ADRs)
- A4: the stochastic model uses peculiar velocities (velocity minus the local circular velocity); reason with numbers in SPEC 5.2.
- A4: impact parameter uniform over the disc (cos² θ uniform), not an isotropic normal (SPEC 5.4).
- A4: collisions act at the end of the integrator step on the synchronised state, so E1 sub-stepping needs no special case (SPEC 7).
- A4: hard-sphere contact normal from the straight relative path back to the contact (SPEC 8), which removes the bias of a too grazing normal for deep overlaps.
- A4: Haff test (T7) checks T / T₀ at t₀ only, with 3 % tolerance: the SE of T(t) is about 1.4 / √N, so 2 % at two times would need several 10⁵ particles.
- AJ (2026-11-07): Q1 smooth spheres, Q2 box cells with three sizes, Q3 `every_steps` default 1, Q4 determinism required (SPEC 13).
