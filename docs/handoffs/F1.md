## Decisions made (link ADRs)

No ADR: all of these are cheap to reverse.

- Toolchain pinned to Rust 1.99 (not floating `stable`), so a new clippy release cannot break CI without a change in the repository. A0 updates the pin in its own pull request.
- Edition 2024, resolver 3, `publish = false` for every crate.
- `unsafe_code = "deny"` for the whole workspace. A crate that needs `unsafe` allows it locally and links an ADR.
- Workspace members by glob (`crates/*`, `apps/*`): every directory there must be a crate.
- Internal dependencies follow `docs/PLAN.md` section 8: every crate uses `fring-model`; `fring-analysis` also uses `fring-io`; `fring-run` uses `fring-cpu`, `fring-gpu`, `fring-io`; `fring-bench` uses `fring-cpu`, `fring-gpu`.
- `fring-web` is a plain library for now. A7 sets `crate-type = ["cdylib", "rlib"]` and adds wgpu in W1.
- One CI job (not one per check) to pay the setup time once. CI also builds `fring-model` for wasm32, because `docs/PLAN.md` section 6.2 requires it.
- Gates are rows on the board, with role AJ. "Blocked by" means "cannot start before". C3 waits for V2, C4 for V3 and R1 for C4, so that each reference exists before the comparison.
