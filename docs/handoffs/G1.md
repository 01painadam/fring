# G1: GPU precision spike
Role: A3  Branch: ws/a3-g1  Status: review
Updated: 2026-11-01

## Goal and acceptance criteria
From `docs/PLAN.md` section 9 and gate G1: compare precision options for the Wisdom-Holman integrator (ADR 0003) on circular and eccentric orbits over 10⁴ orbits. The options of the plan, adapted to the Kepler drift: (a) f32, (b) f32 with double-single (DS) accumulation, (c) DS throughout, plus mixed options (B+, D). *Done when:* ADR 0006 picks the cheapest option that meets PLAN section 10 (GPU against CPU, 10³ orbits, non-chaotic: Δa < 0.01 km, phase < 10⁻⁵ rad), and gives an explicit recommendation on GPU or CPU for the science runs.

A0 decisions (2026-11-01):
- wgpu and pollster approved.
- Test against PLAN section 10 as written; ADR 0006 shows each option's error next to the CPU's own error.
- GPU for science runs only if the cheapest passing option is at least 3 times the CPU throughput.
- Probe first; DS built on the guarded primitives with a fail-closed self-test (A0 accepted after the probe).

## Done
- ADR 0006 (`docs/adr/0006-gpu-precision.md`), status proposed. **Result: option D passes** (phase at most 6.1 × 10⁻⁶ rad, Δa at most 1.2 × 10⁻³ km at 10³ orbits, with and without moons) at 1.1 × 10⁹ particle-steps/s on the M4 GPU, 16 times the CPU (6.9 × 10⁷). **Recommendation: the GPU runs the science runs with D; C stays as the GPU reference mode; W2 uses A.**
- Probe on the M4: plain DS fails (Metal fast math; wgpu-hal does not turn it off); guarded DS works; `fma` fused; division and sqrt within 1.73 ULP. `probe::self_test` fails closed.
- Code in `crates/fring-gpu`: `gpu.rs`, `wf32.rs`, `ds.rs`, `probe.rs`, `spike.rs`, `spike_gpu.rs`; shaders `ds.wgsl`, `trig.wgsl`, `probe.wgsl`, `spike.wgsl`; examples `g1_probe`, `g1_precision`, `g1_bench`; test `tests/gpu_twins.rs` (ignored, needs a GPU).
- Evidence in `docs/adr/0006/`: probe output, summary, series and per-particle CSV files, benchmark CSV, plot `g1_phase.png`, scripts `remez_sincos.py` and `plot_g1.py`.
- Dependencies: wgpu 30.0.1, pollster 1.0.1; rayon as a dev-dependency of fring-gpu. Clean build of the workspace with all targets: dev 5.4 s to 13.9 s, release 7.2 s to 20.0 s.
