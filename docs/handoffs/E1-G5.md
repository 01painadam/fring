# E1-G5: GPU against E1-REF (test G5 of E1-GPU)
Role: A5  Branch: ws/a5-e1-g5  Status: review
Updated: 2026-11-10

## Goal and acceptance criteria
PLAN section 9, E1-GPU: the GPU agrees with the CPU and with E1-REF. Add a GPU backend maker to `fring-e1`; run layers 1 and 2 on the GPU in production mode D+ (ICR-011); apply the E1-REF limits with `validation/scripts/e1_compare.py`. No limit is changed.

## Done
- `apps/fring-run/src/e1.rs`: `BackendKind` (cpu, gpu), `check_variants` (pure function: `substep` on the GPU is refused before any backend is built), `gpu_backend(radii_km)` (`Options { mode: Mode::Dp }`, set explicitly, `FRING_GPU_MODE` is ignored; then `set_moon_radii_km`), `backend_label` (header text with mode and adapter name).
- `apps/fring-run/src/bin/fring-e1.rs`: option `--backend cpu|gpu`. Default variants: `plain,substep` on the CPU, `plain` on the GPU.
- ICR-011 mu_eff and a0 come from `[frame] reference_semi_major_axis_km = 140220` in the config, on both backends.
- Tests: `gpu_backend_refuses_the_substep_variant_without_an_adapter` (normal); `gpu_layer1_smoke` (`#[ignore]`: five encounters, same count, finite). `cargo test -p fring-run` passes.
