- Core functions use `Read`/`Write`; the crate builds for wasm32.
- `serde_json` added to the workspace dependencies (A0 file, allowed for this change).
- 34 tests in `fring-io`. The 10^6 test (with and without velocities, in memory) takes about 1.5 s in a debug build.
