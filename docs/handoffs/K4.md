## Finding (2026-11-09, seed 1 pair done, window orbits 80-200)
Stochastic (ST) against hard sphere (HS), same seed: c_rho 7.25 / 9.43 mm/s, c_z 4.73 / 0, collisions per particle per orbit 1.27 / 5.85, nu 0.0073 / 0.067 m2/s. HS c_z is exactly 0: the start is planar (z = 0, vz = 0; `Distribution::Core` has no inclination or vertical seed, `crates/fring-model/src/config.rs`), and hard-sphere contact normals d/|d| lie in the plane, so HS stays a monolayer. ST normals are random in 3D, so ST gets vertical motion. The two runs are therefore not the same physical system; no agreement test is possible until HS has a vertical seed. Also 160383 deep HS collisions (mostly in the first 2 orbits, 15569 in orbit 2 from a 1e5 particle monolayer at tau 0.1). Queue stopped after seed 1; s2 runs killed and not used.
