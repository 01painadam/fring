## Goal and acceptance criteria
PLAN section 9 B2: run `fring-bench` again with stochastic collisions (K5) for N = 10^4 to 10^7. Done when the new table is in `docs/benchmarks.md`, with the new time for the stretch target (10^7 particles, 30 years; 8.1 h with D+ at G2), and one line says whether a 30-year run matrix (S1) fits the budget of section 11.
A0 decisions (2026-11-09): sub-stepping is CPU only (ICR-004 amendment 2); on the GPU "E1-GPU" means flag + freeze + radius rule. States: cold core (B1 rows) and the A3-ANALYSIS band (`docs/results/configs/chaos-map-full30.toml`: 139,700 to 141,100 km, seed 20261102, reference orbit 140,222.43 km). Collision parameters from SPEC section 10: s = 1e-5 km, W = 8e8 x (10^6 / N), L_x = 0.05 km, L_y = 10 km, L_z = 0.04 km, constant restitution 0.5, every_steps 1 and 10, one sensitivity point with L_x = 0.2 km at 10^6. 5 repeats, one raw CSV row per repeat. One `fring-run` end-to-end check at 10^6, 1 year, all GPU features. S1 line: 30 yr / 356.25 s = 2.66e6 steps; one run with all features against 8 h at 10^6 and 10^7; matrix cost for M = 8, 16, 32 runs in hours and 8 h nights.

Without them the run is the B1 matrix (3 repeats, same table, same ephemeris length). B2 output: `report::csv_b2` (one row per repeat) and `report::markdown_table_b2` (median, min to max, spread, ratio to the base row, candidates and pairs per particle per collision step, weighted occupancy).

- Added state `dense` (sigma 0.3 km, SPEC resolved-core width) beside the two A0 chose: the B1 core and the band have weighted occupancy 1.0 at 10^5 (smoke run), so they have almost no candidate pairs. Drop it with `--states core,band` if A0 prefers.
- A0 2026-11-09: collision rows run each repeat on a fresh backend (`measure::measure_fresh`; one extra backend for the calibration and read-back); per-repeat statistics are in the CSV. All three states stay. 10^4 and 10^5 collision rows stay, with the overfull column.
- Tests: `cargo test -p fring-bench` 19 pass, 1 ignored.

- Pass cost scales with N, not with the hash size M (7 ns per particle at 10^5 and 10^6; floor 0.3 ms below 10^5).

## Memory at N = 10^7 with collisions (GPU D+, chaos off)
Computed from the code, then checked: a 1-point run at 10^7 (dense state, every_steps 1 and 10) completed (`runs/logs/b2-fit-1e7.log`). cap = N rounded up to the workgroup size.
GPU (M = 2^24 hash buckets = next power of two of N; mpad = M + 1 rounded up to 1024; nb = mpad / 1024):

| Buffer | Size | At N = 10^7 | Where |
|---|---|---|---|
| state (6 planes x 8 B) | 48 cap | 480 MB | `stepper.rs:209,235` |
| status + drop_step | 4 (8 + 2 cap) | 80 MB | `stepper.rs:244` |
| bin counts | 4 (mpad + 8) | 67.1 MB | `bin.rs:773`, made at `bin.rs:798` |
| bin starts | 4 (mpad + nb) | 67.1 MB | `bin.rs:774` |
| bin keys | 8 cap | 80 MB | `bin.rs:775` |
| sorted index | 4 cap | 40 MB | `bin.rs:776` |
| sorted keys | 8 cap | 80 MB | `bin.rs:801` (same size as keys) |
| collide `uw` | 16 N | 160 MB | `collide.rs:314` (`mk((16 * n) as u64, rw)`) |
| collide `en` | 4 (2 N + 4 chunks) | 80 MB | `collide.rs:315` (chunks = N / 256) |
| staging for `particles()` | 48 cap | 480 MB (host-mappable) | `backend.rs:369` |
| small (uniforms, tally, moon table) | | under 1 MB | |

Total about 1.6 GB (1.1 GB without the read-back stage). Largest single buffer 480 MB, far below the 4 GiB limit. The bin buffers grow with M, so their size is 2^24 words and not N.
Host: the initial state (7 f64-sized columns, about 0.5 GB), the `State<M4>` vector of the start-up (48 B x N = 480 MB, `stepper.rs:236`), its packed copy and the byte copy (another 2 x 480 MB, freed after upload), `GpuBackend::snapshot` (about 0.5 GB), ids 40 MB and energy0 80 MB (`backend.rs:117-125`). Peak at start-up about 2.5 to 3 GB; the same code ran at 10^7 in B1. The unified memory is 16 GiB, so 10^7 with collisions fits. Chaos is refused with collisions, so the 128 B per particle case does not arise.
CPU at 10^7 is not run with features (limit 10^6): its state is f64 and the cell list adds keys, order and groups; the K2-CPU collision step is about 0.6 s at 10^7.
