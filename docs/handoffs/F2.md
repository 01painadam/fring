## Open questions / blockers

For AJ at gate G0:

1. **Who writes physics in `fring-model`?** PLAN section 6.1 puts force functions, analytic formulas (and so the Hermite interpolation) in `fring-model`, which A0 owns, but tasks C1 to C3 belong to A2. Proposal: A2 may add `crates/fring-model/src/physics/` (forces, analytic formulas, interpolation, frame conversions) and A0 reviews. This needs a change to the ownership table in `AGENTS.md`.
2. **Initial conditions have no task.** PLAN section 7.4 describes the distributions (now in the config as `core`, `band`, `clump`), but no task generates particles from them. Proposal: add it to R1 (A5) or C4 (A2).
3. **Params format (L2).** `SaturnParams` has the field names `gm_km3_s2`, `reference_radius_km`, `j2`, `j4`. L2 can use these names in `params/saturn.toml` so that it deserializes directly, or raise an ICR.
4. **Frame conversion for snapshots (F3).** Snapshots store rotating-frame f32 positions; `ParticleView` is inertial f64. The conversion needs n₀ = n(a₀) with J2/J4 (PLAN section 7.2). It belongs in the physics module of item 1.
