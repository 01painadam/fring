# G3: chaos indicator on the GPU
Role: A3 (and A2 for the CPU part)  Branch: ws/a3-g3  Status: review
Updated: 2026-11-02

## Goal and acceptance criteria
PLAN section 9 G3: chaos indicator on GPU (shadow particle), matches the CPU indicator for 1,000 particles. A0 decision: shadow particle with MEGNO as classifier (ICR-003, ADR 0008); done-when test tied to a CPU baseline.

## Done
- ICR-003 (accepted), ADR 0008 (method, formula, sweep, thresholds, results).
- `fring-model`: `[diagnostics.chaos]`, `ChaosReport`, `Backend::chaos`, `physics/chaos.rs`.
- `fring-cpu`: shadow particles in `CpuBackend` (bit-identical for any thread count and any call split at multiples of K).
- `fring-gpu`: `shaders/chaos.wgsl` (kernel `chaos_renorm`), Rust twin `chaos.rs`, twin test `tests/gpu_chaos.rs`, backend integration.
- `fring-io` / `fring-run`: `chaos.csv`, `meta.json` `chaos` field, `docs/snapshot-format.md` section 8a, `apps/fring-run/configs/chaos-map.toml` for A8.
- Done-when test `tests/chaos_done_when.rs`: rules 1, 2, 4 pass for D+ and C; the "2 times the baseline" part of rule 3 fails because the baseline (1e-7 km) is too small (A0 decision pending, see ADR 0008). Logs in `docs/adr/0008/`.
- Throughput with chaos on: D+ 4.6e8, C 2.3e8 particle-steps/s (half of off).

## Next step (one concrete action)
A0 decides the baseline displacement (1e-7 km as written fails rule 3; 1e-4 km passes all rules), then merge.
