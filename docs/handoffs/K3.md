## Goal and acceptance criteria
From `docs/PLAN.md` section 9: hard-sphere model on the CPU (cell list). *Done when:* K1 tests pass. Scope as K2: `fring-collide` only; the call from `CpuBackend` is a later board task (K3-CPU, A2).

## Plan (SPEC section 8)
- **Model.** `fring_collide::hard_sphere::HardSphereModel` (radius s, restitution law). Real particles (W = 1), acts at every integrator step (no `every_steps`). It has no randomness: the pair order is fixed by particle ids and the contact normal comes from the geometry. So "same seed, bit-identical" holds trivially, and the seed is not an input. Results do not depend on the cell order or the array order (pairs are sorted by id).
- **Cells.** Same code as K2: `Domain::build_cells` (rotating frame, n0 t reduced mod 2 pi, y from phi0, particle ids in order). Cell edges: L_x = L_z = 2s (1 + 10^-6); L_y = D / n_y with n_y = floor(D / (2s (1 + 10^-6) a0 / rho_min)), at least 1, so that a pair closer than 2s is always in the same or a neighbouring cell. The factor a0 / rho_min is the curvature: an arc length y = a0 phi is longer than the distance at a radius below a0. The grid is made at each step from the radius range of the active particles (no state). The 10^-6 covers the rounding of x, y, z (about 10^-11 km) against a contact distance of the order of 10^-2 km.
- **Overlap detection.** Particles sorted by (cell, id) (`CellList`, reused). For each cell, the 27 neighbours (azimuthal index wraps modulo n_y; radial and vertical do not wrap in the ring; the neighbour list is deduplicated when n_y < 3). Neighbour cells are found by binary search in the sorted cell keys (no hash map, so wasm32 and determinism are safe). A pair (i, j) with id_i < id_j and |r_i - r_j| < 2s (inertial positions) is listed once. The list is sorted by (id_i, id_j).
- **Resolution (SPEC 8).** In that order, with the current velocities: skip if d . g >= 0; contact normal from the straight relative path (tau > 0 with |d - g tau| = 2s, in the form without cancellation; n = (d - g tau)/|.| if tau <= h, else d/|d|); `pair::collide`. Deep collision: overlap depth 2s - |d| > 0.2 s, counted in `CollisionStats::deep_collisions`. No position correction.
- **API for K3-CPU (same style as K2).** `HardSphereModel::from_config(&Collisions)`; `full_ring_domain(a0, n0) -> Domain` (its cell sizes are placeholders; the model makes its own grid at each step; only a0, n0, phi0 and D are used); `collide_step(&domain, t_s, h_s, &ids, Some(&active), &mut state) -> Tally`. For rayon: `find_pairs` (read-only, can run per cell) and `resolve_pairs` (sequential, the order matters).
- **Box adapter** (`testkit` feature): `BoxModel` for the periodic cube (min-image separation, cells of edge at least 2s, wrap in all three axes) through the same `find_pairs`/`resolve_pairs` core.
- **Tests (`tests/k3_hard_sphere.rs`).** K1-T4 to T7 and T9 on the model (quick and full, all of SPEC 11, T5 for all four epsilon and the power law); pair finding against a brute-force O(N^2) search (random rings, with and without the wrap, and the box); a pair across the azimuthal wrap of the full ring at several times; n_y < 3; the curvature case (particles at rho < a0); the active mask; order independence (array order, cell order); K1-T8 for hard spheres (a rigid ring at one radius stays cold); a collision test with the contact normal (deep overlap, tau > h); `deep_collisions` count.
- **Verification.** `cargo test -p fring-collide` (quick), `cargo test -p fring-collide --release -- --ignored` (full), clippy `--all-targets`, wasm32 check.
