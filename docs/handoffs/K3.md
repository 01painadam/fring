## How it works (SPEC 8)
- No randomness, so no seed. The pair order is fixed by the particle ids and the normal comes from the geometry. Same input gives the same bits; array order and cell order do not matter (pairs are sorted by `(id_i, id_j)`).
- Cells: the K2 `Domain` machinery with a grid made at each step: L_x = L_z = 2s (1 + 1e-6); L_y = D / n_y with n_y = floor(D rho_min / (2s (1 + 1e-6) a0)), at least 1. The azimuthal index wraps; with fewer than 3 cells neighbours are deduplicated. Neighbour cells are found by binary search (no hash map).
- The pair distance is the inertial distance of the positions; the cells are only a search structure.
- Resolution as in SPEC 8: skip d . g >= 0; contact normal by the path back (n = d/|d| if tau > h); deep collision = overlap depth above 0.2 s, counted in `CollisionStats::deep_collisions`.

## API for K3-CPU (same style as K2)
```rust
let model = HardSphereModel::from_config(&cfg.collisions).unwrap();      // once
let domain = model.full_ring_domain(a0, n0).unwrap();                    // once; a0, n0 as in K2
// at every integrator step, on the synchronised state (no every_steps):
let tally = model.collide_step(&domain, t_s, step_s, &ids, Some(&active), &mut state);
// tally.collisions -> StepStats::collisions_since_last; tally.stats -> StepStats::collision (sum with `+=`)
```
For rayon: `model.find_pairs(&domain, t_s, &ids, Some(&active), |i| position(i))` is read-only (the cells are independent) and returns pairs sorted by id; `model.resolve_pairs(&pairs, h_s, |i, j| d, &mut vel)` must stay sequential (the pairs share particles, the order matters). `collide_step` builds a cell list each step (a sort of the active particles).

## Open questions / blockers
- The hard-sphere quick T4, T6 and T7 take about a minute each without optimisation. They are `#[cfg_attr(debug_assertions, ignore)]`, so a debug `cargo test` (CI) skips them; they run in `cargo test --release`. A0 runs them in release in the review (A0 decision, 2026-11-07).
- An initial overlap is outside the model (SPEC 8). A rigid ring that starts overlapped got velocity changes of 6.7e-8 km/s from grazing pairs with a tilted normal. K1-T8 (b) for hard spheres therefore uses a rigid chain at 1.01 contact distances: 0 collisions and exactly 0 change (the limit is 1e-12 km/s). The shear of a ring with several radii is real physics for hard spheres (neighbours collide), unlike the stochastic model with peculiar velocities.

## Decisions made (link ADRs)
- A4: hard spheres use the inertial separation of the positions (frame independent). The rotating-frame cells are only a search structure.
- A4: the cell grid is made at each step from the smallest radius of the active particles, so no state is kept between steps.
