# B1: fring-bench
Role: A5  Branch: ws/a5-b1  Status: done
Updated: 2026-11-02 12:00

## Goal and acceptance criteria
`fring-bench`: particle-steps per second for CPU and GPU at N = 10^4 to 10^7. Done when: results table in `docs/benchmarks.md` with machine details.

## Done
- `apps/fring-bench` (library plus binary): `cli`, `matrix`, `measure`, `report`. Default matrix has 30 points and takes about 152 s on the M4.
- `sysinfo` moved from `fring-run` to `fring-io` (`fring_io::sysinfo`), with `machine_facts()` added. `fring-run` uses it from there.
- `docs/benchmarks.md`: machine, method, results, comparison with PLAN 11, memory.
- Tests: 11 unit tests (arguments, matrix, step choice, CSV, Markdown, one tiny CPU point) and one `#[ignore]` GPU test.

## Next step (one concrete action)
None for B1 (A0 reran the default matrix on the M4: same numbers within 1 % on the GPU and 5 % on the CPU). Later: re-run `cargo run -p fring-bench --release` and update `docs/benchmarks.md` when the collision kernels (A4) are in.

## How to verify the current state
```sh
cargo test -p fring-bench                          # 11 pass, 1 ignored
cargo test -p fring-bench --release -- --ignored   # tiny GPU matrix, about 6 s, needs a GPU
cargo run -p fring-bench --release -- --quick      # about 30 s; CSV in runs/bench/
```
Expected: rates near 6.5 x 10^7 (CPU) and 9.5 x 10^8 (GPU D+) at N = 10^5.

## Open questions / blockers
- None. Not tested: N above 10^7 (the buffer limit allows 89 million; memory is shared with the CPU).

## Decisions made (link ADRs)
- No ADR. No new external dependency; `fring-bench` now depends on `fring-io` (workspace crate).
