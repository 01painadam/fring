## Open item 1 (AJ): the Safari 26 check

About 10 minutes. The Mac mini runs macOS 26, so Safari 26 has WebGPU on by default.

- **S0, build and open.** In the repository: `apps/fring-web/scripts/build.sh && python3 -m http.server 8080 -d apps/fring-web/dist`. Then open `http://localhost:8080` in Safari. (If the page is already on the public host, use that address instead: the same steps then also check the host.)
- **S1, start.** Expected: the status line shows "Checking GPU arithmetic...", then "Preparing the moons (a few seconds)...", then it clears. No error box. The footer shows "GPU: <name>". **If "The GPU arithmetic check failed" shows, stop and tell A0:** Safari's shader compiler then breaks the double-single arithmetic (M16), and the page cannot run in Safari as it is.
- **S2, bench.** Open `http://localhost:8080/?bench&counts=1e5&modes=off,side,overlay`. Keep the tab in front and the window visible for about 45 s (3 cells of 3 s warm-up and 10 s, plus the rebuilds). **Pass:** mean 30 fps or more and 5th percentile 25 fps or more in each row. Copy the table from the page (select the text, or a screenshot) into the PR or the chat.
- **S3, zoom (M24).** Open `http://localhost:8080` again. In each of the four views (Inertial, Rotating, On Prometheus, On Pandora), at the default speed, scroll to zoom on the ring until the view width in the readout is a few km. Watch for about 10 s. **Pass:** the dots move smoothly; no dot shakes or jumps. Then do the same once with Compare = Overlay in the Rotating view.
- **S4, a full run.** Speed to the maximum (500 h/s). Compare = Side by side, press "Set to now", then Compare = Off. Let the run go to the end (87,600 h at 500 h/s, about 3 minutes; keep the tab in front). **Expected:** the "Dropped: ..." line starts at zeros and the numbers rise; at the end the time stops, Play is disabled and "End of the moon data. Press Restart to start again from t = 0." shows. Press Restart: t = 0 and the counts go to zero.
- **S5, console.** Safari Settings, Advanced: tick "Show features for web developers". Then Develop, Show JavaScript Console. **Expected:** no red errors. The bench of S2 also wrote the user agent and one CSV row per cell there; copy them if that is easy.

## Decision to accept (AJ): the web uses mode Dp, not mode A

- ADR 0006 decision 3, and G2 decision 3, say "the web toy (W2) uses option A (plain f32)". W2 used **Dp** (A0 decision of 2026-11-02, `docs/handoffs/W2.md`).
- Reason: `GpuStepper` has only the modes D, Dp and C (`crates/fring-gpu/src/wh.rs`); option A exists only in the G1 spike (`src/spike.rs`, `shaders/spike.wgsl`). Dp is the science mode, so the web shows the same precision as the science runs, and it still gives 60 fps at 10⁵ in Chrome.
- Cost: Dp depends on the double-single guard. A browser or GPU whose shader compiler breaks the guard fails the start-up self-test, and the page shows "The GPU arithmetic check failed" and does not run. This is why S1 matters. Option A would run blurred on such a device instead (Δa 6 to 8 km RMS at 10³ orbits); a mode A in `GpuStepper` would be new work for A3.
- **A0 recommends:** accept Dp, and A0 writes an addendum to ADR 0006 after the approval. If S1 fails in Safari, A0 comes back with a plan (a mode A fallback, or a per-browser choice).

## Open issues and risks (known limits of the first public demo)

- **Only one GPU tested:** the Apple M4 (Chrome, and Safari after S1 to S5). On other GPUs the self-test decides; the web-only projection shader was checked natively on the M4 only (M24).
- **Touch:** no pinch zoom (W1). Phones and tablets can look but not zoom.
- **Memory:** a particle count that does not fit the device is caught only by a pre-check against the WebGPU limits (W2-COMPARE). A real out-of-memory error is not caught.
- **Test particles only.** No collisions (phase 4). A dropped particle is one that left the system or entered a moon (ICR-006, radius rule); the counts are shown, and the run goes on.
- **The W2-DROP fps** rest on AJ's "All good", without numbers. S2 gives the first fps numbers after W2-DROP.
