### Speed against PLAN section 11 (test particles, no collisions)

The production step is 150 steps per orbit (gate G1). A 30-year run is then 2.7 × 10⁶ steps. The 8 h budget needs 9.4 × 10⁷ particle-steps/s for 10⁶ particles and 9.4 × 10⁸ for 10⁷.

## Decisions made in phase 2 (for AJ to accept or reverse)

1. **ADR 0006: precision of the GPU.**
   - Metal has no f64. Science runs use **D+**: position and velocity in double-single (two f32 per value, 48 B per particle), Kepler drift in double-single, the J2 kick in double-single, and J4, J6 and the moons as f32 magnitudes along the double-single position.
   - **C** (double-single throughout) is the GPU reference mode, at half the speed of D+.
   - **D** (all kick magnitudes in f32) is faster (D+ costs 14 % of D's speed) but fails PLAN 10 in the tail. It stays as a fast mode that is not for science.
   - The web toy (W2) uses **A** (plain f32).
   - Metal fast math breaks plain double-single. The code has a guard, and a start-up self-test that fails closed.
   - Lesson (also in the ADR): 47 particles hid the tail of D. A precision claim needs the maximum and the 99th percentile over thousands of particles.
2. **ADR 0007: moons on the GPU from a host-computed kick table.** The CPU fills the moon positions and the indirect term in f64 for each block of steps, with the same function as the CPU backend, and uploads them. So the GPU and the CPU see the same moons, and there is no Hermite interpolation in WGSL. The web toy can do the same in wasm.
3. **ADR 0008 and ICR-003: chaos indicator.**
   - A shadow particle at d0 = 1 km (radial), renormalised every K = 100 steps (0.67 orbit), with MEGNO ⟨Y⟩ from the renormalised series.
   - Classes: regular ⟨Y⟩ ≤ 2.5, chaotic ⟨Y⟩ ≥ 5, uncertain between them. A1-ANALYSIS adds "bounded" (⟨Y⟩ < 1.5).
   - A plain sum of logarithms cannot classify, because Kepler shear makes a regular orbit grow by a factor of about 9,400 in 10³ orbits.
   - The chaos indicator halves the speed (2 times the work per step).
   - The done-when baseline displacement is 10⁻⁴ km (AJ approved on 2026-11-02). No tolerance was relaxed.
4. **Plots:** Python with Altair (Vega-Lite), in a separate uv project `crates/fring-analysis/python/`. Each figure is a PNG and a Vega-Lite JSON spec, which the web app can use later.

## Open issues and risks

- **Other GPUs.** The D+ result was not rerun with the WGSL worst-case model for division and square root (ADR 0006, risk 2). On a GPU other than the M4, run the start-up self-test and the G2 done-when test before a science run.
- **Close encounters.** Per-particle sub-stepping near Prometheus (PLAN 7.3) is not implemented. With d0 = 1 km the chaos indicator leaves its linear range in close encounters. A1-ANALYSIS reports the closest-approach distribution.
- **Indicator and run length.** ⟨Y⟩ grows with time for chaotic orbits, so only runs of equal length can be compared.
- **Speed without collisions.** All speeds above are for test particles.
- Albers et al. 2012 is still not verified (see G0).
