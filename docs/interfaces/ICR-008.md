# ICR-008: moonlet distribution (`kind = "moonlet"`)
Requested by: AJ (web scenario, task W2-MOONLET), written by A0  Date: 2026-11-03
Status: Accepted by A0 2026-11-03. AJ chose the options in the Claude Code session: a "Velocity" control with all three modes, and a fixed start 180° from Prometheus (the web sets the longitude).

## What

A new variant of the config enum `Distribution` (`[particles.distribution]`, `docs/PLAN.md` section 7.4):

```toml
[particles.distribution]
kind = "moonlet"
semi_major_axis_km = 140222.43   # radius of the circular orbit of the centre
longitude_deg = 180.0            # inertial longitude of the centre at t = 0
packing_radius_km = 20.0         # particles uniform in a sphere of this radius
velocity = "synchronous"         # "synchronous" | "centre" | "circular"
```

- `crates/fring-model/src/config.rs`: `Distribution::Moonlet { semi_major_axis_km, longitude_deg, packing_radius_km, velocity }` and `enum MoonletVelocity { Synchronous, Centre, Circular }`. Validation: a > 0, longitude finite, 0 < packing radius < a. `velocity` has no default.
- `crates/fring-model/src/physics/initial.rs`: positions uniform in the ball, `r = R u^(1/3)`, `cos(theta) = 1 - 2u`, `phi = 2 pi u`, from counter words 0 and 1 of particle `id` (so all three modes have the same positions for one seed). `vz = 0` in each mode.
  - `synchronous`: `v = n z × r`, with the exact n at a (`frequencies`). At rest in the frame that turns about Saturn with the centre.
  - `centre`: the circular velocity of the centre point for every particle (as `clump`).
  - `circular`: the circular velocity at the cylindrical radius of the particle.

`core`, `band`, `eccentric_band` and `clump` do not change.

## Why

AJ asked for a web scenario that starts all test particles in a loosely packed moonlet at a selected orbital radius and packing radius (W2-MOONLET). The shared initial conditions belong in `fring-model/src/physics/` (`AGENTS.md`), so the web and `fring-run` use the same generator. `clump` is Gaussian and has only the "centre" velocity, so it cannot give a hard packing radius or the other two modes.

The three modes spread differently. Hill's equations put the guiding centre of a particle that starts at radial offset x0 with along-track velocity vy0 at `4 x0 + 2 vy0 / n`: vy0 = 0 (synchronous) gives 4 x0, vy0 = -n x0 (centre) gives 2 x0, vy0 = -1.5 n x0 (circular) gives x0. With the exact frequencies the first two get a factor (n/kappa)² = 1.00934 at 140,222 km. The test `moonlet_guiding_centres_spread_as_hill_predicts` measures the slopes 4.03735, 2.01868 and 1.00000 (20,000 particles, R = 20 km), equal to the prediction to 5 digits. For R = 20 km at the core (orbit 14.9 h), the strand spreads 3π Δa per orbit: 1,508, 754 and 377 km, so it wraps the ring in about 1.0, 2.0 and 4.0 years.

## Roles affected

- A2: new code in `physics/initial.rs` (written by A0 with this ICR, as for ICR-007; A2 may review).
- A7: uses it in W2-MOONLET.
- A5, A8: `fring-run` and `fring-analyse` accept the new kind with no change. `fring-analysis::map::guiding_radius_km` uses the initial `|r|` for it (its fallback arm), which is not the guiding centre; a map of a moonlet run would need an update there.

## Migration

None. The change is additive; existing configs parse and give the same particles.
