# ICR-001: add J6 to Saturn's gravity field
Requested by: A0  Date: 2026-11-01
Status: Accepted

## What

- `fring_model::SaturnParams` gets a field `j6: f64` (zonal harmonic J6, no unit). `validate` checks that it is finite.
- `params/saturn.toml` gets `j6 = 8.6764e-5` in `[saturn]` (Jacobson 2022, same data file as J2 and J4; status in `params/sources.md`).
- `docs/PLAN.md`: J6 is in scope (section 2); the potential in section 7.1 has the term −J6 (R/r)⁶ P₆(z/r); the frequencies in section 7.2 have J6 terms:
  - n² = Ω_K² [1 + (3/2) J2 q² − (15/8) J4 q⁴ + (35/16) J6 q⁶]
  - κ² = Ω_K² [1 − (3/2) J2 q² + (45/8) J4 q⁴ − (175/16) J6 q⁶]
  - ν² = Ω_K² [1 + (9/2) J2 q² − (75/8) J4 q⁴ + (245/16) J6 q⁶]

  A0 derived the J6 terms with sympy, with the method of `docs/literature/derivations/n_kappa_nu.py`. They are exact for a circular equatorial orbit in this potential.
- New test `crates/fring-model/tests/params.rs`: `params/saturn.toml` loads into `SaturnParams`.

## Why

Gate G0 evidence (`docs/gates/G0.md`, question 3; `docs/literature/formulas.md`). At the core (a = 140222.43 km):

- J6 raises the apse precession by 0.0021 °/d, which is 23° over 30 years.
- J6 moves the m = 110 corotation-eccentricity resonance by 0.056 km. That is the size of its uncertainty (0.05 km), and the massive core is under 1 km wide.
- The cost is one more term in the force.

J8 to J12 together change the apse precession by only 0.0001 °/d, so they stay out of scope.

AJ approved this at gate G0 on 2026-11-01.

## Roles affected

- **A2 (C1, C2):** the force function includes J6; the gradient test covers it. C2 compares the measured precession with the section 7.2 formulas, including J6.
- **A3 (G2):** the WGSL force and its Rust twin include J6.
- **A6 (V1 to V3):** REBOUNDx `gravitational_harmonics` has J2 and J4 only. Add J6 as an additional force in the REBOUND scripts.
- **A1:** no open task. A0 made the change to `params/saturn.toml` and `params/sources.md` under this ICR.

## Migration

No code uses `SaturnParams` yet apart from tests. A struct literal of `SaturnParams` now needs `j6`. The test backend in `crates/fring-model/tests/backend.rs` is updated.
